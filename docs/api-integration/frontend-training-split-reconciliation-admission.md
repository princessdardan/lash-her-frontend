A fully confirmed cancellation can settle, provided no earlier operation-local uncertainty was recorded. As with the pre-existing training-split exception path, a split admission error prevents the later uncaptured-commerce batch. A successful split entry settles before that batch acquires its separate admission. With admission off, per-order failures remain logged and the later capture batch still runs; thrown query failures retain their prior behavior. Direct helper callers execute directly unless they supply a runner.
