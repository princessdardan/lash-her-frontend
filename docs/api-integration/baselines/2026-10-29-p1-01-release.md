## Reproduce the release check

Check out the frontend and both API repositories at the three full SHAs above,
with their normal sibling directory names. Create a separate frontend clone named
`baseline`, detached at `a08e4659ab37cd989f7d87dab0116f87eac965ec`, and install frontend dependencies with `npm ci`.
From the frontend release checkout, run the contract commands above and:

```sh
npm run contracts:release-check -- --sources .. --release-revision a08e4659ab37cd989f7d87dab0116f87eac965ec --baseline ../baseline/contracts/api-integration/v1 --baseline-revision a08e4659ab37cd989f7d87dab0116f87eac965ec
```
